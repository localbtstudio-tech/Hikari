# Hikari — A Lantern Ascent 🏮

A minimalist 2D browser game generated with the assistance of AI.

## 🎮 About

Hikari is an atmospheric 2D game where players guide a paper lantern through a dark sky, avoid obstacles, and collect rewards while trying to reach a higher score.

The project explores how AI can turn a natural-language idea into a playable browser game.

## ✨ Features

- 2D gameplay using HTML Canvas
- Keyboard and touch controls
- Score tracking and best-score persistence
- Minimalist visual design
- Responsive interface for desktop and mobile

## 🛠️ Technology Stack

- React
- TypeScript
- Vite
- HTML Canvas
- Tailwind CSS

## 🤖 AI Generation

**Hikari was generated with the assistance of Grok AI.**

The purpose of this project is to experiment with AI-assisted game creation and explore how effectively AI can translate a game concept into a working application.

The project is presented as an AI-assisted creation, not as a game written entirely by hand.

## 🧪 Testing Status

The project still requires a complete verification of its build, automated tests, gameplay behavior, and deployment compatibility.

Its current status should not be interpreted as proof that every feature has been fully tested.

## 🚧 Status

Experimental project — generated with AI and subject to further testing.

## 🎯 Objective

To explore the capabilities and limitations of AI in game development, from generating the initial concept to producing a playable web experience.
